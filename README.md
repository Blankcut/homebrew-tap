# Blank Cut Homebrew tap

Homebrew packages for [Blank Cut](https://blankcut.com)'s command-line tool, `blankcut`.

**Not published yet.** Once the first release lands here:

```sh
brew install blankcut/tap/blankcut
```

Homebrew asks you to trust a third-party tap the first time you use it. The `blankcut` CLI needs a
Blank Cut account — sign up at [meerkat.blankcut.com](https://meerkat.blankcut.com), or run
`blankcut login`, which walks you through it.

Packages here are generated by the CLI's release pipeline. Please don't open pull requests against
them; they'll be overwritten on the next release.
